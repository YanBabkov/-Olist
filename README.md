# Дашборд продуктовых метрик: Olist E-Commerce

##  Описание проекта

Интерактивный дашборд в Power BI на основе реальных данных бразильского маркетплейса **Olist** за период **2016–2018 годов**.

Цель проекта — проанализировать поведение покупателей, динамику продаж и ключевые бизнес-метрики маркетплейса, а также представить результаты в виде наглядного интерактивного отчёта.

##  Подготовка и преобразование данных

Данные были загружены и преобразованы **напрямую в Power BI** без предварительной обработки в Excel или других инструментах.

### Загрузка

Все 9 CSV-файлов загружены через **«Получить данные» → Text/CSV** в Power BI Desktop. После загрузки открыт редактор **Power Query** для преобразования.

### Преобразования в Power Query

- **Типы данных** — колонки `payment_value`, `price`, `freight_value` загрузились как текст из-за американского формата чисел (разделитель — точка). Исправлено через **«Изменить тип» → «Использовать языковой стандарт» → English (United States)** → Decimal Number
- **Заголовки** — таблица `product_category_name_translation` загрузилась без заголовков (Column1, Column2). Исправлено через **«Использовать первую строку в качестве заголовков»**
- **Типы дат** — колонки с датами (`order_purchase_timestamp`, `order_delivered_customer_date` и др.) приведены к типу DateTime

### Модель данных

После загрузки настроена **реляционная модель данных** — связи между таблицами созданы вручную в режиме «Модель»:

```
orders ─ customers
orders ─ order_items ─products ─ category_translation
orders ─ order_payments     └─ sellers
orders ─ order_reviews
orders ─ DateTable (таблица дат)
```

Таблица дат создана через DAX:

```dax
DateTable = CALENDAR(DATE(2016,1,1), DATE(2019,12,31))
```

С добавлением вычисляемых столбцов `Month`, `Year`, `MonthYear`, `MonthIndex` для корректной сортировки по временной оси.

Направление кросс-фильтрации между `order_items → products` и `products → category_translation` установлено как **«Оба»** для корректной фильтрации по категориям.

##  Метрики и DAX-меры

Все меры хранятся в отдельной таблице `_Measures`:

| Мера | Формула | Описание |
|---|---|---|
| Выручка (GMV) | `CALCULATE(SUM(payment_value), order_status = "delivered")` | Суммарная выручка по доставленным заказам |
| Количество заказов | `CALCULATE(DISTINCTCOUNT(order_id), order_status = "delivered")` | Уникальные доставленные заказы |
| Средний чек | `DIVIDE([GMV], [Orders Count])` | Средняя сумма одного заказа |
| Покупатели | `DISTINCTCOUNT(customer_unique_id)` | Уникальные покупатели |
| Средний рейтинг | `AVERAGE(review_score)` | Средняя оценка заказов (из 5) |

##  Структура дашборда

Дашборд состоит из **одной основной страницы — Overview**.

### Страница Overview

**KPI-карточки (верхняя строка):**
- Средний чек — **160 BRL**
- Количество заказов — **96 тыс.**
- Выручка (GMV) — **15,4 млн BRL**
- Количество покупателей — **93 тыс.**
- Средний рейтинг заказов — **4 / 5**

**Графики:**
- **Динамика выручки по месяцам** — линейный график, показывает рост с дек 2016 по ноя 2018
- **Количество заказов по месяцам** — столбчатый график, наглядно демонстрирует рост бизнеса
- **Способы оплаты** — круговая диаграмма (credit_card 78%, boleto 18%, voucher 2%, debit_card 2%)
- **Карта по выбранным штатам** — картограмма

**Интерактивные фильтры (срезы):**
- По дате (ползунок)
- По штату покупателя (выпадающий список)
- По категории товара (выпадающий список)
- По способу оплаты (список)

##  Ключевые инсайты

- **78% выручки** проходит через кредитные карты — доминирующий способ оплаты
- **Пик продаж** приходится на ноябрь–декабрь 2017 (сезонный рост + Black Friday)
- **São Paulo** генерирует наибольшую выручку среди всех штатов
- Категории **bed_bath_table**, **health_beauty**, **computers_accessories** входят в топ по выручке
